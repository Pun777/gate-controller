ESP32 · USB

ติดตั้งโปรแกรมลงบอร์ด ESP32

เสียบสาย USB ระหว่างบอร์ดกับคอมพิวเตอร์ แล้วกดปุ่มด้านล่างครั้งเดียว ไม่ต้องติดตั้งโปรแกรมใดๆ

เบราว์เซอร์นี้ใช้ติดตั้งไม่ได้ กรุณาเปิดหน้านี้ด้วย Google Chrome หรือ Microsoft Edge บนคอมพิวเตอร์ (Windows, Mac หรือ Linux) โทรศัพท์มือถือยังใช้ไม่ได้

ก่อนกดติดตั้ง

    กำลังเขียนโปรแกรม0%
    1. ในหน้าต่างที่เด้งขึ้น เลือกรายการที่มีคำว่า USB (เช่น “USB Serial Port (COM7)” ไม่ใช่ Bluetooth) แล้วกด “เชื่อมต่อ”
    2. ตรวจรุ่นบอร์ด
    3. เขียนโปรแกรมลงบอร์ด
    4. รีสตาร์ทบอร์ดให้เริ่มทำงาน

    ขั้นต่อไป

      กำลังรอบอร์ดรายงาน IP…
      โปรแกรม: … เวอร์ชัน: … รองรับ: …
      หาบอร์ดไม่เจอ หรือติดตั้งไม่สำเร็จ
      • ลองเปลี่ยนสาย USB สายชาร์จมือถือบางเส้นจ่ายไฟได้อย่างเดียว ส่งข้อมูลไม่ได้
      • ปิดโปรแกรมอื่นที่ใช้บอร์ดอยู่ เช่น Arduino IDE, Serial Monitor หรือหน้านี้ที่เปิดซ้ำอีกแท็บ
      • ให้บอร์ดเข้าโหมดรับโปรแกรม ต่อขา IO0 ลง GND แล้วถอดไฟ-เสียบไฟใหม่ (บอร์ดที่มีปุ่ม BOOT ให้กดค้างไว้แทน) ติดตั้งเสร็จแล้วถอด IO0 ออก
      • สาย TX/RX ต้องต่อไขว้ TX ของตัวแปลงต่อ RX0 ของบอร์ด และ RX ต่อ TX0
      • ติดตั้งไดรเวอร์ USB ถ้ารายชื่อในหน้าต่างว่างเปล่า ดูตัวอักษรบนชิปเล็กๆ ใกล้หัว USB ของบอร์ด: CP2102 / CP210x หรือ CH340 / CH341 ติดตั้งแล้วถอดสายเสียบใหม่
      ข้อความจากบอร์ด (สำหรับผู้ดูแล)
