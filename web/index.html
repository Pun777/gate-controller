กันบอร์ดพัง

  • ไฟเลี้ยง 5V เท่านั้น ห้ามต่อ 12V/24V เข้าขา 5V
  • ไฟจากตัวแปลง: ใช้ขา 5V ไม่ใช่ 3V3 (3V3 จ่ายไฟไม่พอ ทำให้บอร์ดรีเซ็ตวน)
  • ใช้ไฟแยก: ถอด VCC ของตัวแปลง และต่อ GND ร่วม
  • ระบบตรวจไฟตกและสายผิดก่อนเขียนทุกครั้ง และเช็ก MD5 หลังเขียน
  • ค่า IP ในบอร์ดไม่ถูกลบตอนอัปโหลด
  • อัปเดตผ่าน LAN แล้วใช้ไม่ได้ บอร์ดกลับเวอร์ชันเดิมเอง

ไม่เจอพอร์ตของบอร์ด

    
หน้าเว็บมองไม่เห็นพอร์ตเองเหมือน Arduino IDE ต้องกด “เลือกพอร์ต…” แล้วเลือกจากหน้าต่างของเบราว์เซอร์ ถ้าในหน้าต่างไม่มีรายการ ให้เช็กตามนี้

    
    
      
  1. ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ (มือถือ, Firefox, Safari ใช้ไม่ได้)
    2. 
      
  2. เสียบตัวแปลง USB เข้าคอมพิวเตอร์ ไฟบนตัวแปลงควรติด ลองเปลี่ยนช่อง USB
    3. 
      
  3. เปลี่ยนสาย USB สายชาร์จมือถือบางเส้นส่งข้อมูลไม่ได้
    4. 
      
  4. ติดตั้งไดรเวอร์ ตามชิปบนตัวแปลง แล้วถอดเสียบใหม่:
        CH340 / CH341 ·
        CP2102 / CP210x ·
        FTDI
    5. 
      
  5. เช็กใน Device Manager (คลิกขวาปุ่ม Start → Device Manager → Ports (COM & LPT)) ต้องเห็น เช่น “USB-SERIAL CH340 (COM5)” ถ้ามีเครื่องหมาย ! แปลว่าไดรเวอร์ยังไม่ถูก
    6. 
      
  6. ในหน้าต่างเลือกพอร์ต เลือกรายการที่มีคำว่า USB, CH340, CP210x หรือ FTDI อย่าเลือก Bluetooth
    7.
